# Pemjar_Echo_Server_TCP

repository ini berisi hasil dari uji coba echo server TCP yang dibuat untuk pemenuhan tugas mata kuliah Pemjar

Echo server adalah server yang mengembalikan persis apa yang dikirim kepadanya. Klien mengirim halo ,
server membalas halo . Tidak ada gunanya untuk pengguna, tetapi sangat berguna untuk belajar dan untuk
menguji: bila echo server membalas, berarti sambungan, port, dan program Anda sudah benar. Semua server
yang lebih rumit, termasuk Loket Antrean, dibangun dari kerangka yang sama.
